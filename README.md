# TLSKit External Dependencies

This GitHub Repo provides the external dependencies needed for TLSKit. Specifically, it provides:

- `curl`
- `openssl`

These dependencies are configured to suit the needs of TLSKit, and are not suitable
as general-purpose libraries that can be used in other projects. While you are free
to use these libraries in your app or project, we will not provide support for any
issues arising from the configuration choices or packaging design.
